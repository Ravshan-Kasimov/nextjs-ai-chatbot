# Internationalization (i18n)

This application supports multiple languages through a simple, lightweight i18n system.

## Supported Languages

- **English** (en)
- **Russian** (ru) - Русский (Default)

## How to Use

### Switching Languages

Users can switch languages using the language switcher in the sidebar header:
1. Click the globe icon with the current language name
2. Select desired language from the dropdown
3. The selection is saved in localStorage and persists across sessions

### For Developers

#### Adding Translations

1. **Update translation files** in `lib/i18n/locales/`:
   - `en.ts` - English translations
   - `ru.ts` - Russian translations

2. **Add new translation keys** to both files:
   ```typescript
   export const en = {
     // ...existing translations
     myNewKey: "My new text",
   };
   ```

3. **Use translations in components**:
   ```tsx
   import { useI18n } from "@/lib/i18n";
   
   function MyComponent() {
     const { t } = useI18n();
     
     return <div>{t.myNewKey}</div>;
   }
   ```

#### Dynamic Values (Interpolation)

For strings with dynamic values, use placeholders. The placeholder name in curly braces `{name}` must match the key in the object passed to `interpolate()`:

```typescript
// In locales/en.ts
toggleThemeMode: "Toggle {mode} mode",

// In component
import { useI18n, interpolate } from "@/lib/i18n";

const { t } = useI18n();
const text = interpolate(t.toggleThemeMode, { mode: "dark" });
// Result: "Toggle dark mode"
```

#### Adding New Languages

1. Create a new translation file in `lib/i18n/locales/` (e.g., `fr.ts`)
2. Import and add to `translations` object in `lib/i18n/context.tsx`
3. Add language option to `LanguageSwitcher` component
4. Update the `Locale` type in `lib/i18n/context.tsx`

## Architecture

The i18n system is built with:
- **React Context** - For global state management
- **localStorage** - For persisting language preference
- **TypeScript** - For type-safe translations

No external i18n libraries are used to keep the bundle size minimal.
